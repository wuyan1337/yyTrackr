API 文档

认证方式

所有 API 请求都需要使用 API 密钥认证，请在请求头中附带密钥：

# Authorization 请求头（推荐）
Authorization: Bearer sk_your_api_key_here
# X-API-Key 请求头（备选）
X-API-Key: sk_your_api_key_here

API 接口

订阅接口

方法 接口 说明
GET /api/v1/subscriptions 获取全部订阅
POST /api/v1/subscriptions 创建新订阅
GET /api/v1/subscriptions/:id 获取订阅详情
PUT /api/v1/subscriptions/:id 更新订阅
DELETE /api/v1/subscriptions/:id 删除订阅

统计与导出

方法 接口 说明
GET /api/v1/stats 获取订阅统计
GET /api/v1/export/csv 将订阅导出为 CSV
GET /api/v1/export/json 将订阅导出为 JSON

iCal 订阅

方法 接口 说明
GET /ical/:token 订阅 iCal 日历源（公开链接，基于 Token 验证）

MCP 服务器（AI 集成）

SubTrackr 内置了 Model Context Protocol（MCP）服务器，允许 AI 助手通过自然语言读取和管理订阅。

工具 说明
list_subscriptions 列出全部订阅
get_subscription 按 ID 获取订阅
create_subscription 创建新订阅
update_subscription 更新已有订阅
delete_subscription 删除订阅
get_stats 获取订阅统计
配置示例

将以下内容加入你的 Claude Desktop 或 Claude Code MCP 配置：

{
  "mcpServers": {
    "subtrackr": {
      "command": "subtrackr-mcp",
      "args": [],
      "env": {
        "DATABASE_PATH": "/path/to/subtrackr.db"
      }
    }
  }
}

请求示例

获取订阅列表

curl -H "Authorization: Bearer sk_your_api_key_here" \
http://localhost:8080/api/v1/subscriptions

创建订阅

curl -X POST \
-H "Authorization: Bearer sk_your_api_key_here" \
-H "Content-Type: application/json" \
-d '{
"name": "Netflix",
"cost": 15.99,
"schedule": "Monthly",
"status": "Active",
"category_id": 1
}' \
http://localhost:8080/api/v1/subscriptions

获取统计信息

curl -H "Authorization: Bearer sk_your_api_key_here" \
http://localhost:8080/api/v1/stats
返回示例：
{
  "total_count": 15,
  "active_count": 12,
  "total_cost": 245.67,
  "categories": {
    "Entertainment": 45.99,
    "Productivity": 89.00,
    "Storage": 29.99
  }
}
